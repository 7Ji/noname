# 国战角色称呼

国战中的 `get.translation(player)`、角色数组翻译和 `player.getName()` 使用同一称呼：

| 公开状态                   | 示例              |
| -------------------------- | ----------------- |
| 全暗（包括明置后再次全暗） | 三号位(暗将/暗将) |
| 仅主将明置                 | 三号位(曹操/暗将) |
| 仅副将明置                 | 三号位(暗将/荀彧) |
| 双将明置                   | 三号位(曹操/荀彧) |
| 主将移除为明置士兵         | 三号位(魏兵/荀彧) |

斜线前后固定对应主、副将，不表示本次技能来源。称呼读取当前槽位和明暗状态，不依赖 `player.name` 中的历史称呼。武将 ID 的字符串翻译、武将牌姓名和选将按钮仍使用武将名。`getName(true)` 保留对话框 HTML 包装。

角色右键/悬停帮助菜单在国战中提供“查看主将”和“查看副将”。自己或当前控制的角色可查看尚未明置的武将；其他角色仅显示已明置且存在的槽位入口，两个入口优先在同一行居中排列，空间不足时换行；明置槽位打开对应武将的资料，并使用该槽位的头像和皮肤语音。点击时再次检查明暗状态，旁观者不获得控制视角的查看权限，录像中按录像明暗标记判断。其他模式保留“查看资料”。

称呼实时读取引擎已有的 `getSeatNum()`，不保存国战专用座次字段。开局事件和发牌前初始化从一开始的 `seatNum`；换座时复用通用逻辑更新座次，并刷新角色旁的座位标签。阵亡、视角或控制权变化不重新编号。联机恢复使用通用快照已有的 `seatNum`；录像初始化和换座同步处理该字段，旧录像从初始化记录的 `unknownN` 恢复。座次不可用时显示“未知座位”。

日志继续保存生成时的文本，后续明暗变化不改写历史记录，旧录像日志也保留原文。录像中的动态称呼读取录像明暗标记，替换主将时同步更新主将槽位。

源码变动限制在国战目录内，没有新增通用API，也没有修改通用录像、卡牌或其他武将包。国战通过已有模式覆盖机制调用原有帮助渲染，再调整当前对话框的角色标题和资料入口；卡牌动画也仅替换返回文本中的角色标题。录像使用国战独立的处理表，不修改共享处理表。

为保持这一边界，直接调用 `get.translation(player.name)` 的通用流程、其他武将包和聊天称呼恢复原行为。这些旧入口仍可能显示旧式单将称呼，当前不再宣称“全部角色称呼统一”。日志等本来传入角色对象的入口、国战中的 `getName()`、帮助标题和卡牌动画使用双将称呼。

扩展应传入角色对象获取称呼。直接翻译 `.name`、解析称呼字符串或覆盖 `_tempTranslate` 的扩展需要自行适配；`_tempTranslate` 仍具有最高优先级。

隔离回归验证：`node scripts/tests/guozhan-names.test.mjs`。测试执行源码方法并模拟浏览器节点，覆盖明暗切换、槽位替换、阵亡后座次、对话框、日志、重连及新旧录像数据，以及其他模式的默认称呼、资料入口、动画HTML和通用录像处理表不被修改；不代替真实客户端的联机和界面验证。
